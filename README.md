This project, SkyMonitor NOAA Weather Radio Archive, has one goal: To archive as many NWR EAS alerts as possible on publicly available audio streams. 100% for free, you can view all these archives endlessly, download files, or if you'd like every single capture on a single day, for a certain transmitter, etc-- you can email me at contact@skymonitor.app and I can provide the downloads.
