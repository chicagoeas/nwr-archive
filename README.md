This project, SkyMonitor NOAA Weather Radio Archive, has one goal: To archive as many NWR EAS alerts as possible on publicly available audio streams. I do this via my Raspberry Pi running 24/7, checking NWS alerts continiously, and recording available audio streams when an EAS alert comes through. 100% for free, you can view all these archives endlessly, download files, or if you'd like every single capture on a single day, for a certain transmitter, etc-- you can email me at contact@skymonitor.app and I can provide the downloads. Check it out today!
